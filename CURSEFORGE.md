# Item Borders: Storage Compat

## Summary

Adds Item Borders' rarity-based borders to items displayed in custom storage interfaces.

## Description

Item Borders: Storage Compat is a client-side compatibility mod that brings Item Borders' rarity-based borders to custom storage interfaces. It currently supports Refined Storage and Tom's Simple Storage Mod, respects your existing Item Borders settings, and does not need to be installed on the server.

Item Borders and Iceberg are required. Refined Storage and Tom's Simple Storage Mod are optional; install either or both depending on which storage mods you use.
