# Item Borders: Storage Compat

## Summary

Adds Item Borders' rarity-based borders to items displayed in custom storage interfaces.

## Description

Item Borders: Storage Compat is a client-side compatibility mod that brings Item Borders' rarity-based borders to custom storage interfaces. It currently supports Applied Energistics 2, Refined Storage, Tom's Simple Storage Mod, and Beyond Dimensions, respects your existing Item Borders settings, and does not need to be installed on the server.

Item Borders and Iceberg are required. Applied Energistics 2, Refined Storage, Tom's Simple Storage Mod, and Beyond Dimensions are optional; install the storage mods you use.
